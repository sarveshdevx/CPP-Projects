## Adding Future Projects

New projects are added to this repository following a consistent workflow:

1. **Create a numbered folder:** Follow the naming convention (e.g., `04-network-packet-sniffer/`).
2. **Add source files:** Include the required C++ source code and other project files.
3. **Create a project README:** Document the overview, features, concepts, requirements, and execution instructions.
4. **Update the root README:** Add the new project to the Repository Structure and Project Index.
5. **Test the project:** Compile and verify that the application works correctly.
6. **Commit and push:** Upload the completed changes to GitHub.
